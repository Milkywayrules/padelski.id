---
name: dio-no-new-options
description: Freeze the option space — refine the current plan only.
disable-model-invocation: true
---

The user is locking scope. Do not introduce new options or tangents.

- Refine, execute, or clarify the **current plan only**.
- If something is ambiguous, ask **one** targeted question — not a new option set.
- If the current plan is missing, state that in one sentence and ask what to lock — do not invent alternatives.

Keep the reply short: current plan in one line, then the single most useful refinement or next step.
